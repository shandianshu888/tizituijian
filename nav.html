/ PROTOCOLS & NETWORK TAXONOMY · 协议与线路知识图谱

主流代理连接协议

VLESS + Reality

新一代去中心化伪装协议，无证书要求，直接借用海外知名大站 TLS 指纹，抗封锁能力目前最强。

Hysteria 2 (歇斯底里)

基于 UDP QUIC 开发，专为高丢包与弱网环境优化，晚高峰暴力发包突破限速首选。

Trojan

将网络流量完美伪装成标准的 HTTPS 网页浏览流量，兼容性好，适合日常办公与流媒体播放。

Shadowsocks (SS)

老牌轻量级加密协议，多客户端支持最完善，搭配商业物理专线（IPLC/IEPL）速度极快延迟极低。

物理线路与骨干网架构

IPLC / IEPL 内网专线

端到端物理光纤专线，流量不经过公网 GFW 审查，晚高峰零丢包、超低延迟，但成本显著高于普通中转。

BGP 多线智能入口

自动识别电信、联通、移动网络并分发至最优接入机房，彻底解决移动墙中墙和跨网结算瓶颈。

公网中转 (Transit)

国内服务器接收流量后加密转发至境外落地机，成本适中，性价比较高，但敏感时期有被封端口风险。

直连线路 (CN2 GIA / 9929)

电信与联通的优质海外直连路由，晚高峰拥堵率较低，但受国际出口总带宽波动态势影响。

规则分流与安全防御

Rule 规则分流模式

根据域名列表和 IP 库自动判断：淘宝/微信等国内流量直连，Google/YouTube 海外服务走代理，省流且不影响日常。

Fallback 自动容灾策略

在客户端中配置主备节点组，当主力节点连续 3 次探测超时时，5 秒内无感知自动切换至备用节点。

DNS 泄露与防污染 (DoH/DoT)

使用加密 DNS 避免运营商劫持真实访问意图，防止因为 DNS 解析污染造成虽然连上代理但打不开网页。

分级安全环境边界
